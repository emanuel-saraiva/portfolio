# Emanuel — Analytics Engineering Portfolio

A static, GitHub Pages-ready portfolio with individual case study pages.

## Run locally

Open `index.html` in a browser. No dependencies or build step required.

## Publish

1. Create a **public** repository named `portfolio` on GitHub.
2. Upload all contents of this directory, preserving the directory structure.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)** and save.
5. Visit `https://YOUR_USERNAME.github.io/portfolio/`.

## Before publishing

- Replace generic contact text with your LinkedIn, GitHub, and email.
- Verify every professional case-study statement and remove anything sensitive.
- Confirm the status of Stargazing milestones.
- If your repository name differs from `portfolio`, adjust the expected URL.

All content is in English; all styles are in `assets/css/style.css`.
