Personal project · Work in progress

Stargazing — Data Engineering

Building the foundations of a Snowflake-based data platform while documenting data engineering architecture and implementation decisions.

SnowflakeSQLRBACdbt (planned)Python (planned)

Project objective

Develop a practical end-to-end data engineering project, progressing from platform organization and access control toward ingestion, transformation, testing, and analytics-ready datasets.

Implemented so far

  • Established a Snowflake database and warehouse for the project.
  • Defined dedicated roles to represent administration, ingestion, transformation, and BI responsibilities.
  • Organized schemas to establish boundaries between data processing layers.

Under development

Role privileges and end-to-end permission checks, source ingestion, dbt transformations, Python workflows, automated testing, and analytical outputs are subsequent phases. They are not represented as complete here.

Engineering focus

The project explores least-privilege access, separation of workloads, clear data layer responsibilities, and reproducible SQL-based infrastructure setup.

Next milestones

  1. Validate privileges for ingestion and transformation roles.
  2. Add an initial, non-sensitive data source.
  3. Introduce dbt models and tests once the underlying data is available.
  4. Document the resulting pipeline with a technical architecture diagram.
Project status is intentionally explicit so that planned features are not confused with completed work.
